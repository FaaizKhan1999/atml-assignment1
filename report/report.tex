\begin{abstract}
  In general, supervised learning solutions generally assume that training and test data are independent and identically distributed. These solutions also assume a closed-set setting: a classification problem where the model only encounters classes during testing that it was explicitly trained to recognise. However, this is normally not the case. An object from a known class may appear with altered textures, colors, positions, or styles; test data may come from new domains; or an input may belong to a class that was not observed during training.   Consequently, a model can perform well in a controlled environment but break down in the real world because it relies on cues or statistical regularities that do not remain stable. This reports examines aspects of learning beyond the aforementioned assumptions, and then forms an argument about what a useful representation should preserve, suppress, and reject. You may find the associated code and \LaTeX files for this assignment in the following GitHub repository: \url{https://github.com/FaaizKhan1999/atml-assignment1}
\end{abstract}
