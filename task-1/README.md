# Task 1: Evaluating Inductive Biases in Vision Models

This repository contains a comprehensive evaluation suite designed to probe the inductive biases of different deep learning architectures (ResNet-50, ViT-B/16, and CLIP). By systematically destroying or isolating specific visual cues—such as color, texture, global shape, and spatial arrangement—this pipeline quantifies how heavily different architectures rely on specific localized or holistic features.

## Experimental Framework

Evaluations are conducted on a balanced 500-image test subset of the STL-10 dataset (Seed: `6304`). Pre-trained backbones are frozen, and standard linear classifier heads are trained for ResNet-50, ViT-B/16, and CLIP, alongside a Zero-Shot CLIP baseline. 

The suite executes the following visual interventions:

*   **Color Bias:** Evaluates reliance on chromaticity by applying a full Grayscale conversion and a fixed Hue Rotation (factor of 0.5). Performance is measured via Top-1 accuracy drop.
*   **Cue Conflict (Shape vs. Texture):** Tests whether a model prioritizes local texture or global shape. Images are generated by combining the shape of one class (e.g., Airplane) with the texture of another (e.g., Cat) using Adaptive Instance Normalization (AdaIN). Evaluated using Shape Bias metrics and Cue Coverage.
*   **Translation Invariance:** Tests spatial sensitivity by translating images by $\delta \in \{0, 8, 16, 32\}$ pixels in all four cardinal directions using reflection padding and shifted cropping.
*   **Patch Shuffling:** Destroys global spatial organization while retaining local pixel evidence. Images are sliced into a $4 \times 4$ grid (56x56 pixel patches) and deterministically shuffled (Seed: `6304`) to evaluate reliance on coherent spatial arrangement.
*   **Representation Analysis:** Measures the Cosine Stability ($I_T$) of the underlying feature embeddings for all transformations. A unified t-SNE projection maps clean and transformed feature spaces to visualize cluster degradation.

## Directory Structure

*   `task-1/analysis/`
    *   `evaluate_baseline.py`: Establishes the clean baseline accuracy for all backbones.
    *   `evaluate_color_bias.py`: Extracts Grayscale and Hue Rotation accuracy drops.
    *   `evaluate_patch_structure.py`: Calculates accuracy drops and consistency for the $4 \times 4$ patch shuffle.
    *   `evaluate_shape_bias.py`: Computes Shape Bias and Cue Coverage from the curated cue-conflict subset.
    *   `evaluate_translations.py`: Generates the displacement curve mapping accuracy and consistency against pixel shift.
    *   `feature_similarity.py` / `representation.py`: Computes Cosine Stability ($I_T$) and generates the unified t-SNE projections.
    *   `visualize_cue_conflicts.py`: Hunts for informative Agreement, Disagreement, and Failure cases in the cue-conflict dataset and renders a visual grid.
*   `task-1/configs/`
    *   `base.yaml`: Configuration settings for the experiments.
*   `task-1/data/`
    *   `cue_conflicts_candidates/`: Directory containing the generated AdaIN images.
    *   `cue_conflicts_metadata.json` & `splits_seed6304.json`: Tracks subset indices and image metadata.
    *   `make_cue_conflicts.py`: The AdaIN style transfer script that generates 450 cross-class candidate images.
    *   `make_subset.py`: Generates the balanced 500-image test subset.
    *   `transforms.py`: Houses the standard normalization pipelines and PyTorch transformation classes (e.g., `ReflectionTranslate`, `patch_shuffle_intervention`).
*   `task-1/models/`
    *   Contains model scripts (e.g., `backbones.py`) for loading ResNet-50, ViT-B/16, and OpenCLIP architectures.
*   `task-1/results/`
    *   Contains all generated JSON data dictionaries and `.png` plots for the final report.
*   `task-1/scripts/`
    *   `plot_summaries.py`: Ingests JSON outputs to render clean, aggregate bar charts.
    *   `train_heads.py`: Trains the standard linear classifier heads for the frozen backbones.

## Code Sources & Acknowledgements

The Adaptive Instance Normalization (AdaIN) pipeline utilized in `make_cue_conflicts.py` is directly adapted from community-standard implementations of the original 2017 paper by Xun Huang and Serge Belongie:
*   **Original Implementation:** The underlying mathematics and spatial logic are based on Xun Huang's original Lua Torch repository ([xunhuang1995/AdaIN-style](https://github.com/xunhuang1995/AdaIN-style)).
*   **PyTorch Translation:** The exact structural translation to PyTorch (including the specific `Net` wrapper, `calc_mean_std`, and `adaptive_instance_normalization` functions) follows the implementation used in Geirhos et al.'s Stylized-ImageNet repository ([bethgelab/stylize-datasets](https://github.com/bethgelab/stylize-datasets)).
*   **Network Weights:** The pre-trained VGG-19 encoder (`vgg_normalised.pth`) and decoder (`decoder.pth`) weights are automatically downloaded from Naoto's PyTorch port ([naoto0804/pytorch-AdaIN](https://github.com/naoto0804/pytorch-AdaIN)). 

To adapt these implementations for modern PyTorch (v2.0+) and the $96 \times 96$ native resolution of STL-10, the interpolation mode was explicitly defined as `BICUBIC` and the style transfer strength ($\alpha$) was tuned to `0.6` to prioritize structural shape retention during candidate generation.
